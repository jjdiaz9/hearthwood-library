Sync between devices

Your phone and computer share one file, hearthwood-library.json, kept in a private GitHub repository that only you can see. Set this up once on each device, with the same repository and token.

How to set it up
  1. On GitHub, make a new private repository, for example hearthwood-data. Don't use the website's repository: it's public.
  2. Make an access token at github.com/settings/personal-access-tokens/new. Under Repository access choose Only select repositories and pick your data repository. Under Permissions → Contents choose Read and write. It needs nothing else.
  3. Enter the repository and paste the token below, then press Save and sync.
  4. On your other device, open this page and do step 3 with the same repository and token.

The token is kept only in this browser and is never put in backups. If it might have leaked, delete it on GitHub and make a new one.
